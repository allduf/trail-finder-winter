# trail-finder-winter

The 3D map's Winter photos for [Trail Finder](https://allduf.github.io/trail-finder/), served at https://allduf.github.io/trail-finder-winter/.
The photos live on the `winter-photos` branch of allduf/trail-finder; `.github/workflows/publish.yml` publishes them here (daily and by hand), outside the main site's 1 GB GitHub Pages limit.
